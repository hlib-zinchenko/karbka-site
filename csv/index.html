Import flashcards from CSV, Excel or Google Sheets

Type your cards in a spreadsheet, save it as CSV and import it into Karbka in a few taps. Hundreds of cards at once, with tags and notes.

Open Karbka

The format

One card per row. Only the first two columns are needed; the rest can be left out.

ColumnWhat goes in it
frontThe front of the card: the word, question or term.
backThe back: the translation, answer or definition.
tagsOptional. Several tags separated by |, like verb|N5|food.
notesOptional. A note shown on the back of the card.
deckOptional. A deck name, to import several decks from one file into a collection.

Good to know

  • Separator. Comma, tab or semicolon: Karbka finds it by itself. Excel in many countries saves with semicolons, and that works too.
  • Header row. Optional. A first row like front,back, question,answer, term,definition or word,translation is recognised and skipped. If it gets it wrong, tick or untick “First row is a header” before you import.
  • Commas inside a card. Put the cell in double quotes: "ate, eaten". Spreadsheets do this for you when they save a CSV.
  • Any alphabet. Save the file as UTF-8 so Japanese, Ukrainian, Greek or accented letters come through. Empty rows are skipped.
  • Big files. A deck holds up to 999 cards. A bigger file becomes several decks: “Verbs”, “Verbs 2”, “Verbs 3”…

Save a CSV from your spreadsheet

Make a sheet with the front in column A and the back in column B, add tags and notes if you like, then:

Google Sheets

  1. File, then Download
  2. Comma-separated values (.csv)

On a phone, the Sheets app: ⋮, Share & export, Save as, CSV.

Excel

  1. File, then Save As (or Save a Copy)
  2. CSV UTF-8 (Comma delimited)

Plain “CSV” can break letters outside English; pick the UTF-8 one.

Numbers

  1. File, then Export To, then CSV
  2. Text Encoding: Unicode (UTF-8)

On iPhone and iPad: ⋯, Export, CSV.

Quizlet

  1. Open a set you made, then ⋯ and Export
  2. Keep Tab between term and definition and New line between rows
  3. Copy the text into a file ending in .txt or .csv

Quizlet lets you export the sets you created.

Import it into Karbka

Into a new deck

  1. Open a collection and tap ⋯ at the top
  2. Tap Import CSV and pick the file
  3. Check the preview and the deck name (it’s the file name), then tap Import

In an empty collection, Import CSV is right on the screen.

Into a deck you have

  1. Open the deck and tap ⋯, More
  2. Tap Import CSV and pick the file
  3. Tap Import: the cards are added after the ones already there

The deck column is ignored here: every card goes into this deck.

Several decks at once

  1. Add a fifth column, deck, with a deck name on each row
  2. Import it from ⋯ at the top of the collection
  3. Each name becomes its own deck in the collection

This is the file Share collection makes, so a whole collection moves in one go.

Export back to CSV

To edit cards in a spreadsheet or send a deck to a friend, open the deck and tap ⋯, Share CSV. For a whole collection, with the deck column, tap ⋯ at the top of the collection, Share collection. Excel opens these files with every alphabet intact.

A CSV holds the cards, not your progress. To move everything, levels included, to another device, use Settings, Backup & transfer, Export library.

Your deck is one file away.
